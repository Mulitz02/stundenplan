# Stundenplan BPH

Stundenplan-App für **Projektmanagement Holzbau (BPH)** an der Hochschule Biberach, WS 2026/27.

**App öffnen:** https://mulitz02.github.io/stundenplan

- Alle Veranstaltungen aus dem öffentlichen Studiengangplan im LSF
- Kurse mit einem Tipp an- und abmelden, der Wochenplan baut sich daraus
- Überschneidungen und Ausfälle auf einen Blick
- Auswahl per Link mit Kommilitonen teilen
- Export in den Handykalender (.ics)
- Läuft offline, auf dem iPhone über Safari → Teilen → „Zum Home-Bildschirm“

An- und Abmelden gilt nur für die App, nicht für das LSF. Maßgeblich bleiben die Angaben im LSF, Ausfälle bitte dort prüfen.
