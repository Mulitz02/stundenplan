# Stundenplan HBC

Stundenplan-App für alle Studiengänge der **Hochschule Biberach**, WS 2026/27.

**App öffnen:** https://mulitz02.github.io/stundenplan

- Studiengang wählen, danach Fächer mit einem Tipp an- und abmelden
- Fächer grob nach Semester sortiert (abgeleitet aus den Modulnummern im LSF)
- Wochenplan mit Räumen, Ausfällen und Überschneidungen, springt automatisch auf die aktuelle Woche
- Auswahl per Link mit Kommilitonen teilen
- Export in den Handykalender (.ics)
- Läuft offline, auf dem iPhone über Safari → Teilen → „Zum Home-Bildschirm“

Daten: öffentliche Studiengangpläne im LSF der HBC, Stand siehe App. An- und Abmelden gilt nur für die App, nicht für das LSF. Maßgeblich bleiben die Angaben im LSF, Ausfälle bitte dort prüfen.
